# YousraBank
🏦 Yousra Bank

A simple and secure digital banking web app for managing accounts and transfers.

🌍 Overview

Yousra Bank allows users to register, view balances, make transfers, and track transactions — all in one place.

✨ Features

User registration and login

View account balances and history

Internal money transfers

Secure authentication (JWT / Supabase)

🧱 Tech Stack

Frontend: Next.js + TypeScript 

Backend: Express.js /TypeScript

Database: PostgreSQL + Prisma / Supabase

Deployment: Vercel (frontend), Render  (backend)

🚀 Getting Started

git clone https://github.com/your-org/yousra-bank.git
cd yousra-bank
npm install
npm run dev

📦 Example Endpoints

POST /api/auth/register – Create new account

POST /api/auth/login – User login

POST  /api/auth/send – Make a transfer
